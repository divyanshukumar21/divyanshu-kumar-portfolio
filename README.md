# Divyanshu Kumar - Personal Portfolio

## Project files
- index.html - Home page
- about.html - About page
- projects.html - Projects page
- contact.html - Accessible contact form
- css/style.css - All styling
- script.js - Demo contact-form interaction

## Main requirements covered
- Semantic HTML5
- Accessibility features
- ARIA labels where appropriate
- Keyboard navigation and visible focus
- Skip-to-content link
- SEO-friendly metadata
- Responsive design
- Accessible contact form

## How to run
Open index.html in a browser, or use VS Code with the Live Server extension.
